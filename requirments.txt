# insect/script — 默认依赖：推理 / 验证 / Gradio（Windows · macOS · Linux）
#
# 环境选型：
#   本文件 requirments.txt              日常推理与 Gradio（推荐；不含 onnx 包）
#   requirments-windows-5090.txt        Windows 原生 + RTX 5090：torch+cu130 + onnxruntime-gpu
#   requirments-wsl-5090.txt            Windows 主机 WSL2 + RTX 5090：Linux 轮子；pandas≥2.3.3（含 cp314）
#   requirments-export-onnx.txt         YOLO/检测导出 .onnx（需预编译 wheel，见下）
#   requirments-trt.txt                 Linux NVIDIA：TensorRT .engine + modelopt
#
# ⚠ Python：默认链路须 3.10–3.12。WSL 若是系统 **3.14**，请用 requirments-wsl-5090.txt
#   （勿钉 pandas 2.2.x；3.14 上 onnx 导出仍可能缺 wheel，日常推理可走本 WSL 文件）。
#   Windows 建议：先装 https://www.python.org/downloads/release/python-31210/ ，再建 venv。
#   WSL 若报 pandas meson「Unknown compiler / 无 gcc」：改用 requirments-wsl-5090.txt，
#   不要靠装 gcc 硬编。
#
# ── GPU 服务器推荐安装顺序（避免 torch/torchvision 错位）────────────────────
# 1) pip install -r insect/train/requirements-cuda*.txt
# 2) pip install -r insect/script/requirments.txt
# 3) 导出 .onnx：pip install -r insect/script/requirments-export-onnx.txt
# 4) 导出 TensorRT：pip install -r insect/script/requirments-trt.txt
#
# ── Windows + RTX 5090（驱动 CUDA 13.x，检测 .onnx 要上 GPU）────────────────
#   PowerShell（Windows 原生）：勿只用本文件（会装 CPU 版 onnxruntime，且不带 CUDA torch）。
#     pip uninstall -y torch torchvision onnxruntime onnxruntime-gpu
#     pip install -r insect/script/requirments-windows-5090.txt
#   WSL2（Linux 用户态）：
#     pip uninstall -y torch torchvision onnxruntime onnxruntime-gpu
#     pip install -r insect/script/requirments-wsl-5090.txt
#
# macOS / Windows CPU-only / 非 5090：
#   python -m venv .venv && .venv\Scripts\activate   # Win
#   pip install -U pip
#   pip install -r insect/script/requirments.txt
#   pip install torch torchvision   # 按 https://pytorch.org 选 CPU/CUDA
